구글 P-MAX, 늘려야 할 때와 멈춰야 할 때

구글이 추천한다는 이유만으로 켤 캠페인은 아닙니다.

2026년 8월 19일 · 읽는 데 8분

P-MAX(퍼포먼스 맥스)를 켜는 이유가 "구글이 추천해서"인 계정을 자주 봅니다. 검색·쇼핑·디스플레이·유튜브·디스커버 지면을 하나의 캠페인이 자동으로 나눠 쓰는 구조라, 검색 캠페인처럼 어느 지면에서 얼마가 나갔는지 세부적으로 들여다볼 수 없습니다. 이 블랙박스 같은 특성 때문에 같은 캠페인을 두고 "켜니까 좋아졌다"와 "밑 빠진 독이었다"는 후기가 동시에 나옵니다. 결과가 갈리는 이유는 대부분 켜는 시점의 조건 차이에 있습니다.

아래 수치는 설명을 위한 예시이며 업종·계정 이력에 따라 달라집니다. 판단 기준과 확인 순서만 가져가시길 권합니다.

1. 도입 전 — 계정 상태부터 확인합니다

P-MAX의 자동입찰은 과거 전환 데이터를 기준으로 입찰가를 조정합니다. 데이터가 부족한 상태에서 켜면 부정확한 신호로 예산을 쓰며 학습하게 됩니다.

계정 상태권장
전환 추적 미설치 또는 검증 안 됨도입 보류 — 추적부터 검증
최근 30일 검색 캠페인 전환 30건 미만도입 보류 — 데이터 더 쌓일 때까지 대기
쇼핑 피드 속성 누락·이미지 미흡피드 정비 후 도입
전환 30건 이상 + 추적 검증 완료도입 검토 가능

특히 첫 번째 조건이 가장 흔한 원인입니다. 전환 추적이 부정확한 상태에서 P-MAX를 켜면, 자동입찰이 애초에 잘못된 신호를 좋은 신호로 착각하고 예산을 더 태우는 방향으로 학습합니다. 네이버 프리미엄로그분석·메타 픽셀과 마찬가지로 구글 애즈 전환 추적도 설치 후 데이터가 실제 주문과 맞는지 먼저 확인해야 하며, 설치 자체는 홈페이지 개발자나 관리자의 협조가 필요합니다.

2. 브랜드 검색 잠식을 어떻게 확인하는가

P-MAX는 타겟팅 범위가 넓어 이미 브랜드명을 검색한 사용자까지 잡는 경우가 많습니다. 원래 검색 캠페인이 잡던 전환이 P-MAX 전환으로 이름만 바뀌어 잡히는 것인데, 계정 전체 전환수는 늘어난 것처럼 보여 이 문제를 놓치기 쉽습니다.

구분도입 전도입 후 3개월
검색 캠페인 브랜드 전환 비중42%18%
P-MAX 브랜드 전환 비중0%31%
계정 전체 전환수100108

표의 예시 계정은 전체 전환수가 8% 늘었지만, 늘어난 전환 대부분이 원래도 잡히던 브랜드 검색이 P-MAX로 옮겨간 것이었습니다. 실질적인 증분은 8%보다 훨씬 작았던 셈입니다. 캠페인 인사이트 리포트에서 브랜드 검색어 비중을 주기적으로 확인하고, 브랜드 제외 리스트 기능으로 일부 통제하는 것이 현재로선 가장 실질적인 대응입니다. 다만 검색 캠페인처럼 키워드 단위로 완전히 막을 수는 없다는 점은 감안해야 합니다.

확인 질문

지금 P-MAX 전환수가 늘었다고 보고하고 있다면, 같은 기간 검색 캠페인 전환수는 그대로인지 줄었는지부터 봐야 합니다. 계정 전체 전환수만 보면 잠식을 증가로 착각하기 쉽습니다.

3. 멈춰야 하는 신호

P-MAX는 자산그룹 학습 기간(통상 2주 안팎)이 있어, 초기 며칠 성과만으로 판단하면 이릅니다. 다만 학습 기간이 지난 뒤에도 아래 신호가 이어진다면 확장이 아니라 중단을 검토할 시점입니다.

  • 학습 기간 이후에도 전환당비용이 목표 대비 50% 이상 초과 — 자동입찰이 원하는 수준으로 수렴하지 못하고 있다는 신호입니다.
  • 검색 캠페인 노출 점유율이 줄어드는데 P-MAX 전환만 느는 경우 — 잠식이 진행 중일 가능성이 높습니다.
  • 인사이트 리포트의 신규 고객 비율이 낮고 기존 고객 재구매 위주로만 잡히는 경우 — 새로운 수요를 못 찾고 이미 확보한 고객만 반복 타겟팅하고 있는 상태입니다.

4. 실행 체크리스트

도입을 결정했다면 아래 항목을 켜기 전에 확인합니다.

  • 자산그룹마다 이미지·텍스트 조합을 최소 3세트 이상 구성했는가
  • 브랜드 제외 리스트를 설정했는가 (완전한 통제는 아니지만 최소한의 장치)
  • 예산이 아니라 전환 가치 기준으로 입찰 목표를 잡았는가
  • 신규 고객 획득 목표 입찰 옵션을 검토했는가
  • 학습 기간 종료 시점을 캘린더에 표시해뒀는가 — 초반 성과로 성급히 끄지 않기 위해서입니다

P-MAX는 검색 캠페인을 대체하는 도구가 아니라, 검색이 못 잡는 지면을 넓히는 도구입니다. 순서를 바꾸면 브랜드 검색 성과를 P-MAX 성과로 착각하게 됩니다.

자주 묻는 질문

P-MAX를 켜면 검색 캠페인은 꺼야 하나요?

아닙니다. P-MAX는 검색 캠페인을 대체하는 도구가 아니라 검색이 못 잡는 지면(디스플레이·유튜브·디스커버·지도)까지 넓히는 도구입니다. 검색 캠페인을 끄고 P-MAX만 남기면 브랜드 키워드처럼 확실히 전환되는 영역까지 자동입찰에 맡기게 되어 오히려 비효율이 커질 수 있습니다.

전환 데이터가 적어도 일단 켜서 학습시키면 되지 않나요?

권장하지 않습니다. P-MAX의 자동입찰은 과거 전환 데이터를 기준으로 입찰가를 조정하는데, 학습 초기에 데이터가 적으면 부정확한 신호로 예산을 소진하며 학습합니다. 검색 캠페인에서 먼저 전환 데이터를 쌓은 뒤 도입하는 순서가 예산 낭비를 줄입니다.

브랜드 검색 잠식은 완전히 막을 수 있나요?

완전히는 아닙니다. 브랜드 제외 리스트 기능으로 어느 정도 제한할 수 있지만, 검색 캠페인처럼 키워드 단위로 세밀하게 통제할 수는 없습니다. 캠페인 인사이트에서 브랜드 검색어 비중을 주기적으로 확인하는 것이 실질적인 대응 방법입니다.

P-MAX 성과가 나쁘면 바로 꺼야 하나요?

자산그룹 학습 기간(통상 2주 안팎) 안의 성과만으로 판단하면 이릅니다. 학습 기간이 지난 뒤에도 전환당비용이 목표 대비 크게 초과하는 상태가 이어진다면 그때 중단을 검토하는 것이 순서에 맞습니다.

쇼핑 피드가 없는 서비스업도 P-MAX를 쓸 수 있나요?

쓸 수는 있지만 쇼핑 피드가 있는 계정만큼의 차별화된 이점은 적습니다. 피드 없이는 검색·디스플레이·디맨드젠을 넓게 묶은 캠페인에 가까워지므로, 전환 추적이 정확히 설치되어 있는지가 도입 여부를 가르는 더 중요한 기준이 됩니다.

정리

  • 전환 추적 검증과 최근 30일 전환 30건 확보가 도입의 최소 조건
  • 계정 전체 전환수가 아니라 검색 캠페인 전환수의 변화를 함께 봐야 잠식을 놓치지 않음
  • 브랜드 제외 리스트는 완전한 통제가 아니라 최소한의 장치로 이해할 것
  • 학습 기간(2주 안팎) 이전 성과로 성급히 끄지 말 것
  • 학습 기간 이후에도 전환당비용 초과·잠식 신호가 이어지면 중단을 검토할 것

P-MAX는 껐다 켰다 실험하듯 다룰 캠페인이 아니라, 켜기 전 조건과 켠 뒤 확인 순서가 정해진 캠페인입니다. 지금 계정이 도입 조건을 채웠는지부터 확인하는 것이 순서입니다.

지금 계정에 P-MAX가 맞는 시점인지, 이미 켜져 있다면 잠식이 진행 중인지 함께 확인해 드립니다.
